# Audit anglickych retezcu

Tento adresar obsahuje pomocny skript pro inventarizaci kandidatu na anglicke retezce. Skript je pouze cte a vytvari CSV report; zdrojove soubory nemeni. Workflow rozdeli kontrolu do osmi paralelnich uloh a spoji vysledky do jednoho artefaktu.

Poznamka: jde o heuristickou detekci, nikoli automaticky preklad ani zaruku zachyceni vsech uzivatelsky viditelnych retezcu.
